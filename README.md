Shawnkys Music

«A modern music streaming interface built for a simple, immersive, and responsive listening experience.»

Shawnkys Music adalah proyek web music player yang berfokus pada pengalaman mendengarkan musik dengan antarmuka modern, responsif, dan minimalis.

Project ini dikembangkan sebagai independent project untuk pembelajaran, eksperimen, dan pengembangan teknologi web modern.

Design

Shawnkys Music menggunakan desain yang berfokus pada:

- Minimalist interface
- Dark mode
- Glass / blurred visual elements
- Dynamic background berdasarkan artwork
- Responsive layout
- Mobile-first experience
- Smooth interaction
- Clean navigation

Tujuannya adalah membuat interface yang tetap nyaman digunakan tanpa terasa terlalu ramai.

Getting Started

Requirements

Pastikan sudah ter-install:

- Node.js
- npm
- Git

Installation

Clone repository:

git clone https://github.com/Shawnkys7/ShawnkysMusic.git

Masuk ke directory:

cd ShawnkysMusic

Install dependencies:

npm install

Jalankan development server:

npm run dev

Setelah itu buka alamat localhost yang diberikan oleh Vite.

---

Production Build

Untuk membuat production build:

npm run build

Untuk melakukan preview hasil build:

npm run preview
